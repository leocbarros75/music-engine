LAST TRAIN TO LONDON - PIANO WITH STRINGS
Composer: Jeff Lynne. Original piano arrangement: Zach V.

START HERE
last-train-piano-and-strings.pdf: combined conductor score, including original piano.
last-train-piano-and-strings.musicxml: editable combined score.
last-train-V1/V2/VA/VC/CB: five individual string parts, PDF and MusicXML.
original-piano.mxl: supplied piano source, unchanged.

INSTRUMENTATION
Piano, Violin I, Violin II, Viola, Cello, Double Bass.
One player per string part or larger unison sections. No mandatory divisi.
Bowed strings arco; double bass pizzicato throughout.
Piano remains the principal instrument. Balance strings in rehearsal.

WHAT CHANGED
The piano's musical material is retained. Engraving coordinates and page breaks
are reset, and a split printed 121 + .4 tempo is joined as 121.4 without changing
the playback tempo. 766 newly arranged string notes add sustained harmony,
offbeats, brief answers, and bass punctuation. Source repeats are retained.
This is an additional accompaniment, not a redistribution of the piano notes.

LEARNING AND REPRODUCTION
Read PROCESS.md for the musical plan, voicing algorithm, examples, references,
and limitations. Run arrange.py with Python 3 to regenerate MusicXML and JSON.
Run python3 -m unittest -v in this folder for the eight validation tests.
PDF generation is separate; see PROCESS.md for the MuseScore command.

QUALITY CHECKS
Eight automated tests passed. PDF pages were visually reviewed.
No live performer read-through or audio-based balance assessment was performed.
