LAST TRAIN TO LONDON — STRING ORCHESTRA
Composer: Jeff Lynne. Source piano arrangement: Zach V.

Open last-train-string-score.pdf for the conductor score.
V1, V2, VA, VC and CB are Violin I, Violin II, Viola, Cello and Double Bass.
Each part is supplied as PDF and editable MusicXML.

This edition uses divided string sections. Minimum players for all written
lines: 2 Violin I, 2 Violin II, 4 Violas, 3 Cellos, 1 Double Bass.
Section principals should allocate divisi and confirm bowing in rehearsal.

Read PROCESS.md for the full musical and technical explanation, references,
examples, and reproduction instructions. PERFORMANCE-REVIEW.md provides a
rehearsal feedback template. The score has not been performer-tested.

To regenerate MusicXML (Python 3, standard library only):
  cd to this folder
  python3 transcribe.py
  python3 -m unittest -v
PDF engraving requires MuseScore separately; adjust engrave-jobs.json paths
for your machine. Regenerating MusicXML does not automatically update PDFs.

All 1,942 source pitched note segments are mapped, with 63 octave changes
and 274 separately traced added double-bass segments. See validation.json
and note-map.csv/json. Eight automated tests passed; PDF layout was reviewed.
Original source and extracted XML are included for reproducibility.
